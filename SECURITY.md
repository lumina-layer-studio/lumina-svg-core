# Security policy

## Supported version

Security fixes are maintained on `dev-refactor` for the latest 0.3.x version.
This is an alpha library. It parses SVG input and executes native geometry
code; applications handling untrusted files should isolate processing and
apply an appropriate operating-system resource policy.

## Report a vulnerability

Use GitHub's **Report a vulnerability** option in the repository's
[Security tab](https://github.com/lumina-layer-studio/lumina-svg-core/security)
to submit a private report. Do not disclose an exploitable input in a public
issue before maintainers have had an opportunity to investigate.

Include the package/commit version, platform, a minimal reproducer, steps to
trigger the problem, and its observed impact. Share only files you are
authorized to provide. There is no guaranteed response or remediation deadline.
